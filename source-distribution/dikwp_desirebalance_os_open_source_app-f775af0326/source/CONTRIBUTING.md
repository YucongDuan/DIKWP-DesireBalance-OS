# Contributing

1. Open an issue describing the problem, affected user group, evidence, and intended boundary.
2. Do not add automated coercion, hidden profiling, dark-pattern generation, punitive scoring, or real-world enforcement.
3. Add or update tests for every scoring or routing change.
4. Clearly separate evidence, assumptions, value choices, and operational recommendations.
5. Retain DIKWP / Yucong Duan attribution in relevant documentation.
